# Demo script (3:00 max)

Shot list for one take on the live app. Record real runs only; if any stretch is sped up (the minute of processing), say so on screen.

**Before recording**

- A fresh test site on `/new` with a realistic block target for the wall you'll walk (count rows × blocks per row by hand; write it down, it goes in the video).
- Phone: location and camera allowed for plumbline-ruby.vercel.app, screen recording on, brightness up, battery above 40%.
- Paper and a thick marker. Daylight, wall not in deep shade.
- A second visit from earlier at the same site, so the same-site check has something to compare.
- Desktop: the site page open, logged out of anything personal.
